# 🏛️ Nossa História Capixaba

> Dossiê Histórico Ampliado e Aprofundado: Manifestações, Tradições, Lutas e Resistências Culturais no Espírito Santo.

---

## 📜 Sobre o Projeto
O **Nossa História Capixaba** é um portal educacional e cultural desenvolvido para valorizar, registrar e difundir a rica história do estado do Espírito Santo. O projeto aborda revoltas populares, manifestações culturais ancestrais, personalidades históricas marcantes e perfis de comunidades tradicionais.
